## Preferred Installation

### Fedora Everything

The name sort of sells the picture, **Fedora Everything** edition is an all-encompasing network installation image for all the various spins from the [Fedora Project](https://fedoraproject.org/). This method however, does **require** a network connection, or a local mirror host connection. You can download the iso for Fedora Everything directly [here](https://fedoraproject.org/misc/#everything).

Choose the installation media that corresponds to your system's architecture.

### Fedora Server Edition

If you do not have an available network connection, or don't want to use the [Fedora Everything](https://fedoraproject.org/misc/#everything) iso file, you can download the iso for Fedora Server Edition directly [here](https://fedoraproject.org/server/download/).

Choose the installation media that corresponds to your system's architecture.
