# VaultWarden Migration

Currently, VaultWarden has been running on my Raspberry Pi since I have heard about and started it.

---

## Actual commands followed

Pre-Requisites:

1. Logged into smith-ad using Cockpit URL
2. Opened up **Terminal** on the side menu navigation

First, we know infrastructure is housed at `/srv/infra/` on most SmithLab boxes but, we can determine where exactly the containers live using the following command:

```Shell
docker compose ls
```

This should return a table similar to the following:

```Shell
NAME         STATUS      CONFIG FILES
caddy        running(1)  /srv/infra/caddy/docker-compose.yml
vaultwarden  running(1)  /srv/infra/vaultwarden/docker-compose.yml
```

---

Using this information, we can now `cd` to the `/srv/infra/vaultwarden` directory and run an `ls -alhrt` command to view directory contents. 

```Shell
cd /srv/infra
sudo ls -alhrt /srv/infra/vaultwarden
```

Confirm that the following directories/files exist:

1. data
2. docker-compose.yml

Now inside the `/srv/infra` directory, we want to create a backup archive of the important bits of information:

```Shell
sudo tar \
	--exclude='*/.local' \
    --exclude='*/.bash_history' \
    -czf /tmp/vaultwarden.tar.gz \
    /srv/infra/vaultwarden
```

**Notice:** We are adding `--exclude=` for the `.bash_history` and `.local` file/directory because these are user-specific artifacts generated by administrative shell access and are not required for Caddy operation. Excluding them reduces archive noise but has no functional impact on restoration.

---

Now that we have created our backup archive, we must copy the file to the required destination using the following command:

```Shell
scp /tmp/vaultwarden.tar.gz csmith@fedora-desktop:/storage/smith-lab/migration/
```

**Notice:** `fedora-desktop` is an alias. If not created or known, use IP.

---

Verify the folder structure:

```Shell
tar -tf /storage/smith-lab/migration/vaultwarden.tar.gz \
| sed 's|/$||' \
| tree --fromfile
```

* `-t`                            :  List the contents of an archive
* `-f`                            :  Use archive file; e.g. `tar -f some.tar.gz`
* `sed 's|/$||'`        :  Removes the trailing slash from displayed output
* `tree --fromfile`  :  Reconstructs and displays the directory hirearchy

```
/srv/infra/vaultwarden
├── data
│   ├── db.sqlite3
│   ├── db.sqlite3-shm
│   ├── db.sqlite3-wal
│   ├── icon_cache
│   │   └── [website-icon.png]
│   ├── rsa_key.pem
│   └── tmp
└── docker-compose.yml
```
